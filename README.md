📝To-Do List App (Python)
    A simple and beginner-friendly CLI To-Do List Application built using Python.
This project allows you to add, view, complete, and delete tasks — all stored locally in a JSON file.
## 🚀 Features
- ✔ Add new tasks  
- ✔ View all tasks  
- ✔ Mark tasks as complete  
- ✔ Completed tasks show with **strikethrough formatting**  
- ✔ Delete tasks  
- ✔ Automatically saves to `tasks.json`  
- ✔ Beginner-friendly and easy to extend 

project structure
demo/
│── todo.py
│── tasks.json
│── README.md
└── ex.txt

▶️ How to Run

Clone this repository:

git clone https://github.com/10vi12/demo.git


Navigate to the folder:

cd demo


Run the app:

python todo.py


You will see the interactive menu:

===== TO-DO LIST =====
1. View Tasks
2. Add Task
3. Mark Task Complete
4. Delete Task
5. Exit
